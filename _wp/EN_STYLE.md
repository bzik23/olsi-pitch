# OLSI Systems — Hebrew → English translation style guide

Authoritative reference for every English page of olsi.co.il. Keep terminology and
tone identical across all pages so the site reads as one professional voice.

## Golden rules
1. **Translate visible text only. Never alter HTML.** Keep every tag, attribute,
   class, id, SVG, `data-*`, and link target byte-for-byte. Only the human-readable
   text between tags (and `alt`, `title`, `placeholder`, `aria-label` values) changes.
2. **Do not touch links or asset paths.** Leave every `href`/`src` exactly as-is; a
   separate deterministic step rewrites internal links to the `/en/` tree.
3. **No em dash. Ever.** Use a plain hyphen `-` (locked client preference).
4. **American English.** Spelling (optimize, color, organization), date style, etc.
5. Natural, professional B2B marketing English — not a literal word-for-word gloss.
   Rework sentences so they read as if written by a native copywriter, while keeping
   the same meaning, structure, and section order.
6. Tone: confident, warm, concrete. Address the reader as "you / your business /
   your team". Avoid hype and filler. Match the Hebrew's calm, expert register.
7. Keep numbers, years, phone numbers, prices, and proper nouns unchanged.
